# Color schemes

Each JSON file is an editable Cetruo Desktop color scheme.

- `tone`: `LIGHT` or `DARK` controls grouping in the scheme picker. `AUTO` remains supported for older/custom files.
- `backgroundColor`: the card stock/background color.
- `panelColor`: the rules/text panel background.
- `textColor`: body and footer text.
- `darkTextColor`: title/type/stat text rendered over the card background.
- `overlayColor`: tint used for SVG overlays.
- `imagePadColor`: visible when artwork is smaller than its frame.

Schemes are ordered as Light first, then Dark, and then alphabetically inside each group.
